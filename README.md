# SCED 470 — Fall 2026 Course Site

**Digital Technologies in Mathematics Education** · Boğaziçi University · Assoc. Prof. Serkan Özel

This is a static, no-build website that supplements **Moodle** (the official system of record for
announcements, submissions, and the live XP leaderboard) for SCED 470, Fall 2026. It gives students a
well-organized, always-available reference for the course's gamified XP assessment model, task
specifications, and weekly session plans.

## Pages

| File | Content |
|---|---|
| `index.html` | Home / orientation — the big-picture pitch, the XP system at a glance, quick links |
| `syllabus.html` | Full syllabus — course description, logistics, the XP framework, the 12-week schedule, policies, readings |
| `tasks-faq.html` | Every Weekly Mission and Major Assignment with rubrics, plus the Task Continuity FAQ |
| `weekly-plans.html` | Session-by-session plans for every Tuesday/Thursday class, showing how in-class time scaffolds each week's graded task |

## Source of truth

Content here is derived from two living documents Assoc. Prof. Özel and Claude maintain collaboratively:
the **SCED 470 Fall 2026 Syllabus** and the **SCED 470 — Task & Assignment Specifications**. When those
documents change, this site should be regenerated to match — it is not the source of truth itself.

## Publishing

This repo is served via **GitHub Pages** from the root of the default branch. No build step is required;
`index.html` and its siblings are plain static HTML/CSS.

No student-identifying information is stored in this repository at any time.
